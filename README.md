# Impact Story Network

Impact Story Network startet als öffentlicher Story-Ort für kleine echte Alltagssituationen.

Menschen erzählen kurze, reale Situationen, die eine sichtbare Wendung bekommen können: ein vergessenes Ticket, eine dumme Rechnung, ein teurer Fehler, eine kleine Alltagspanne oder ein Moment, bei dem man sagt: „Das kann doch nicht wahr sein.“

**Claim:** Die Geschichten bewegen Menschen. Die Menschen verändern Geschichten.

## Kernidee zum Start

Der Start besteht aus:

1. einer kurzen öffentlichen Story,
2. Kommentaren, Nachfragen, Zweifeln und Reaktionen der Community,
3. einer kleinen, möglichst zweckgebundenen Geldreaktion,
4. einem sichtbaren Update,
5. einem möglichen guten Ende.

Die Plattform sammelt nicht allgemein Geld für Personen. Sie macht eine konkrete Mini-Mission innerhalb einer Story sichtbar.

Beispiele für zweckgebundene Geldreaktionen:

- Ticket
- Rechnung
- Gutschein
- klarer Mini-Betrag für eine konkrete Wendung

## Positionierung

Keine klassische Hilfsplattform.

Sondern:

> Eine Story-App, in der Menschen auf echte Alltagssituationen reagieren und deren Ausgang sichtbar verändern können.

Der Hauptakteur bittet nicht klassisch um Hilfe. Er erzählt, was passiert ist. Die Community liest mit, kommentiert, fragt nach, zweifelt oder reagiert mit einem kleinen Geldbetrag.

## Was der Start nicht ist

Der Start ist keine private Hilfe-Koordination.

Nicht Teil der Startmechanik:

- Mitfahrten
- Abholungen
- Sachhilfe
- private Treffen
- private Hilfsangebote
- direkte Sachspendenkoordination
- komplexe Fallbetreuung

Breitere Hilfeformen wie Zeit, Wissen, Kontakte, Sachspenden oder Dienstleistungen können später als kontrollierte Ausbaustufe geprüft werden. Sie sind nicht der aktuelle Produktkern.

## Würde und Ton

Der Ton ist leicht, direkt und menschlich.

Humor darf aus der Situation entstehen, aber nicht aus der Erniedrigung der Person.

Die Plattform soll nicht mitleidig, bürokratisch, karitativ oder dramatisch wirken. Sie soll kurze echte Geschichten erzählbar machen und gleichzeitig klare Grenzen schützen: Kritik ja, Entwürdigung nein.

## Hauptbestandteile zum Start

- Storyfeed für kleine Alltagssituationen
- Kommentare als zweite Ebene der Story
- zweckgebundene Geldreaktionen
- sichtbarer Fortschritt
- Updates und Good-End-Mechanik
- Meldefunktion und Kommentar-Moderation
- einfache Verifikation und Missbrauchsbegrenzung
- Datenminimierung und Schutz privater Informationen
- DACH als Startmarkt
