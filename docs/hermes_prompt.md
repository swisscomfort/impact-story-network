# Hermes Startprompt

Erstelle aus diesem Repository eine saubere Projektbasis für `impact-story-network`.

Ziel:
- kein produktiver Code ohne Freigabe
- zuerst Dokumentation, Struktur und Roadmap sauber halten
- App später als Flutter + Supabase planen
- iOS und Android App Store als Ziel berücksichtigen
- DACH als Startmarkt
- Fokus auf Trust, Safety, DSGVO, Monetarisierung und MVP

Aufgaben:
1. Prüfe die Dateistruktur.
2. Prüfe alle Markdown-Dateien auf Konsistenz.
3. Erstelle eine TODO.md mit priorisierten nächsten Schritten.
4. Erstelle eine ROADMAP.md mit 30 Tage, 90 Tage, 12 Monate.
5. Erstelle keine Commits und pushe nichts ohne Freigabe.
